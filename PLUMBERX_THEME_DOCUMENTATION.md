## 🚀 Installation & Demo Import Guide

### Method A: Install via WordPress Admin (Recommended)
1. In your WordPress admin, go to **Appearance > Themes > Add New > Upload Theme**.
2. Choose `plumberx-theme.zip` from your computer.
3. Click **Install Now**, then click **Activate**.
4. You will see a notice from **TGM Plugin Activation** recommending:
   - **Elementor Website Builder** (Required for drag-and-drop layouts)
   - **WooCommerce** (Recommended for shop functionality)
5. Click **Begin installing plugins**, select all, choose **Install**, and activate them.

### Method B: Manual FTP / Local Installation
1. Copy the folder `plumberx-theme` into your WordPress installation at:
   ```
   wp-content/themes/plumberx/
   ```
2. In WordPress Admin, go to **Appearance > Themes** and click **Activate** on **PlumberX**.

## ⚡ Running 1-Click Demo Import

PlumberX includes a **built-in zero-dependency AJAX importer**:

1. In WordPress Admin, go to **Appearance > Demo Import**.
2. Verify the system requirements checklist (Elementor active, memory limit).
3. Click **Import Complete Demo**.
4. The importer executes the 6 stages automatically with a live progress bar:
   - **Step 1/6: Media Assets** — Imports bundled images into Media Library and maps IDs.
   - **Step 2/6: WooCommerce Products** — Creates 6 plumbing store products with prices and featured images.
   - **Step 3/6: Blog Posts** — Imports 4 articles with categories, excerpts, and featured images.
   - **Step 4/6: 12 Full Pages** — Creates all 12 pages with their exact Elementor JSON layouts and remapped media URLs.
   - **Step 5/6: Navigation Menus** — Creates 'Main Navigation' with all 17 items, dropdowns, and assigns them to primary & footer locations.
   - **Step 6/6: Settings** — Sets Front page to 'Home', Posts page to 'Blog', assigns WooCommerce shop page, and flushes Elementor CSS cache.
5. Once complete, click **Visit Your Website** — your site is now an exact 1:1 replica of the demo!

*(Optional: If you prefer the One Click Demo Import plugin (`pt-ocdi`), PlumberX is also 100% compatible with it via `content.xml` and automated post-import hooks).*

## 🎨 Drag & Drop Customization with Elementor

To edit any page:
1. Go to **Pages > All Pages**.
2. Hover over any page (e.g. **Home**, **About Us**, **Services**, **Plumbing Repairs**, etc.) and click **Edit with Elementor**.
3. Click on any section to edit text, phone numbers, prices, images, and button links in the Elementor sidebar.
4. Drag new **PlumberX Elements** from the left panel onto the page.
5. Click **Update** to publish changes instantly.
